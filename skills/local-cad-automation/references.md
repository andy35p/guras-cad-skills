# 本机流程及样例

## AutoCAD 2024

已验证 D:/cad2024/AutoCAD 2024/accoreconsole.exe。使用前检查路径。可用 /i 指定工作副本 DXF 或 DWG，/s 指定 ASCII 脚本。Windows 下将有空格的路径整体引用。使用 ASCII 临时文件名，保存到每次运行独有的新路径。

保存脚本示例，最后留空行。

```lisp
(setvar "FILEDIA" 0)
(command "_.SAVEAS" "_2018" "C:/path/to/work/result.dwg")

```

再启动后台程序并以新 DWG 为输入。用 INSUNITS 和限定在 Model 的 ssget 检查图元、INSERT 与 DIMENSION。读取日志时检测编码。已观察到 UTF-16LE。退出码之外还要检查输出文件、重开日志和预期图元。确认后复制至交付目录。

## 原生读取回归

使用 /i 打开 DWG 副本并用 /s 运行 scripts/inspect.scr。取日志里以 (CADTRAIN 开头的结果行。字段为 INSUNITS 和模型空间计数，依次是总数、直线、圆、块参照、原生尺寸、填充、三维实体。

| 样例 | INSUNITS | 模型空间计数 |
|---|---:|---|
| 三视图.dwg | 1 | 120 / 67 / 11 / 0 / 26 / 4 / 0 |
| 机械零件_左四视图.dwg | 4 | 3519 / 2015 / 32 / 0 / 0 / 0 / 0 |
| 01.平面系统图9.23(1).dwg | 4 | 7881 / 3547 / 220 / 1006 / 1109 / 390 / 0 |

三视图样例的插入单位为英寸。和 A3 PDF 的已知尺寸、原生标注测量值及标注样式核对后再决定单位与比例，避免直接换算整图。四视图样例模型空间没有 DIMENSION，判断尺寸时还应检查文字、线段及布局。平面系统图要保留块和原生标注，并按图层及块定义识别符号，不能只依据总图元数判断内容是否完整。

## 机械三视图标注与出图核对

用 /s 运行 scripts/dimensions.scr 检查有原生标注的 DWG。每行依次给出 DXF 组码 42 的测量值、组码 1 的文字覆盖、组码 3 的样式。用标注类型区分直径、半径和线性尺寸。测量值与纸面显示值不一致时检查样式因子和覆盖值。

已核对三视图样例的 26 个原生标注均使用 Standard，文字覆盖为空。A3 PDF 上抽核的 28、34、7.4、R1、R8、直径 4 和 8 与 DWG 数值相符。INSUNITS=1 仍不足以认定这些数值的实际设计单位。该 PDF 渲染可见尺寸和红色线条，但主体轮廓未清晰显示。不能把该 PDF 当作完整外形基准。出图时检查轮廓图层的打印开关、视口冻结和打印样式，并逐视图对照轮廓与尺寸。
三视图 A3 重打实测：仅开启 PART、DETAIL、HATCH、FRAME、TABLE、BREAK 的打印开关未恢复轮廓。随后在副本上清除这些层图元的颜色组码 420/430，并统一为索引色 7 后，三视图轮廓、剖面线和图框恢复。遇到类似缺线先检查实体颜色覆盖。简体中文版使用 DWG To PDF.pc3 时，实测 A3 纸名为 ISO A3 (420.00 x 297.00 毫米)，着色打印可用 _W。布满纸张输出只用于视觉核对。
隔离验证：仅修改上述图层中模型空间图元的实体颜色，保留图层打印设置，A3 渲染与同时开启图层打印的版本逐像素一致。另存 DWG 重开后 INSUNITS=1，模型图元及各类计数和原图一致。相似案例先在副本上做局部颜色测试。
四视图对照测试：机械零件_左四视图.dwg 直接按 A3 横向、范围、居中、布满、monochrome.ctb、_W 出图。轮廓、中心线、A-A/B-B 剖面和尺寸文字可见，未应用三视图的颜色修正。模型空间 DIMENSION=0 但图面尺寸可见，原生尺寸计数只用于判断可编辑性。密集标注应另做打印比例和字高检查。
