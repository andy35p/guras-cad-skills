# 项目模式与经验

## 机械三视图、实体返工和装配拆图
- 定位基准面、对称轴、孔中心和实际投影法。俯视槽线与主视轮廓不能独立修改后失配。
- 返工优先改既有三维实体，检查布尔操作前后的包围盒、体积及孔槽位置；不要将剖切显示误判为实体切除。
- 装配拆图按实体/零件身份保留独立文件。多个 body 或 part 是并行子成果，不能只保留最后一个编号。
- STEP 转为三视图时区分隐藏线、可见轮廓、中心线，并分别保留必要的尺寸假设和检查说明。
- 当前同机 local-cad-automation/references/solid-rework.md 记录了更具体的实体返工经验，涉及该流程时再读取。

## 厂房改造与多层平面
- 一层、二层、三层可能分别停留在不同有效修订号。按楼层追踪，不能删除所有低于最大 R 号的文件。
- 保留原楼梯位置、入口朝向、上下梯口和挑空关系。复核连接段新增面积与重复计算。
- 老版本面积统计不自动随新图生效。不能将 R02 统计配到 R10 图上并称为最新。
- 现场未知的梁板、楼梯和标高写入待核说明。方案假设与既有结构分别标识。

## 室内立面与家具
- 房间墙宽、净高、家具实际宽高决定标注和出图比例。以成品家具替换占位后重算尺寸，不沿用旧标注。
- 相同房间的四个立面与四个房间的单立面是不同交付范围。按用户要求分文件，避免额外增加局部平面或未要求视图。
- 家具平面符号不能拉伸为立面。低多边形家具投影的细节程度需要先预览，用户要求精细 CAD 家具时优先真正的立面图块。
- 许可逐文件核查。README 与 LICENSE 冲突时记录冲突并改用清晰来源，不自行宣布授权已经解决。
- 保留最终素材说明、尺寸记录和必须附带的许可。来源链接和尺寸在项目说明中核对后使用。
- 同机 local-cad-automation/references/furniture-library.md 及其素材索引用于进一步复用。

## 景观总平面、SU 与 PS
- 从原图外皮多段线、道路曲线及植物图元定位剖切线，记录原坐标、平移量、剖线起终点、观察方向。
- 地坪线与建筑背景投影分别考虑。将切线附近所有建筑包围盒投影会造成重叠，先合并可见轮廓并验证遮挡与距离。
- 住宅与低层商业分别确认或假设高度。一个“统一 30m”案例不能成为默认建筑高度规则。
- 树木可按原图位置抽样；如果为表达层次补充树木，写明植物布置为示意。不能把平地示意称为既有地形。
- SU 可用简化体块、草坪及树冠表达，群组命名并保存剖切平面和正交观察场景。
- PS 中的天空、乔灌木、人物、土壤、铺装、建筑线稿和文字独立分层，注意人物与树高比例。对齐各图地面线和竖向示意值。
- 先用一张局部表现确认方向再批量加工，减少整图反复生成。若用户已经认可某版，后续分层制作保留它的风格与细节完成度。
- 单张导出前隐藏其他图组及文字，检查边缘残字、裁切、透明背景、字号和 A2 排版可读性。
