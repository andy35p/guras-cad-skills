# CAD 绘图、建模与最终交付

先读取当次任务和实际原图，选择对应工作模式。复用已安装的 local-cad-automation 的 DWG 转换、图元核查和家具素材资源。已有安装和库先检查可用性，再决定是否需要新增依赖。

## 识别依据

- 区分单体建筑平面、总平面、装配图、参考照片和示意表现。图层名及文件名不足以确定对象用途，核查图块、代理实体、布局和空间分布。
- INSUNITS=0 或 1 时，结合原生尺寸测量值、标注倍率及已知长度判断实际单位。不要直接全图乘 25.4 或 1000。
- 只有总平面时，可以在用户许可范围内制作景观示意；建筑内部剖面需要楼层、楼梯及洞口依据。已有高度与获准示意高度在图上标明。
- 在副本上操作，保留原坐标与原始文件。附件说明结合用户当前采纳的范围使用。
- 三视图和建筑空间逻辑见 [项目模式](references/project-modes.md)。原生软件执行及故障处理见 [本机工作流](references/windows-native.md)。

## 绘制与表现

模型几何按实际单位创建，文字、尺寸、墙体、门窗、植物、道路分别组织为可编辑对象。反映既有建筑的轴线、楼梯和承重关系时，应保持已确认的位置。

家具先核查平面/立面类型、尺寸、许可和可见几何，再嵌入命名块。参考用户提供的局部图形时，保留来源及使用范围。

彩色表现先确定与 CAD 一致的水平投影、地面线、建筑轮廓。SU 简模、观察方向和剖切位置需对应同一底图。PS 保留可编辑文字和分类图层，嵌入素材或随交付带齐依赖。用最终导出图做视觉验收，避免将简化底稿当作达到参考效果的成品。

图像生成适用于植物、天空等素材和明确标识的表现预览。整图生成可能漂移轮廓、图名和比例，未经核对不能作为精确底图。不能用一张合成图冒充分层 PSD。交付说明如实记录实际使用的软件及仍有差距的环节。

## 验收与整理

分别验证文件可打开、实体与单位、跨图一致性、视觉效果。AUDIT 无错误仅证明文件结构，不代表尺寸和设计准确。

仅在用户要求整理或清理后执行删除。默认交付只保留同一子任务的一套最终成果及所需格式和说明。步骤见 [最终文件管理](references/finalization.md)。脚本 scripts/finalize_outputs.py 通过明确保留清单和 SHA256 检查执行已授权的清理，不自动判断最新版本。

本机用户已指定集中成果目录 D:/mutipleimage。按日期/项目保留组织关系，跨项目同名文件分别存放。该约定可被当次用户指定路径覆盖。

已归档成果位置及案例状态见 [项目索引](references/project-index.md)。仅在复查旧项目时读取。
